# ML Hands-On

> **Learning Machine Learning & Deep Learning by building algorithms from scratch.**

## 📖 About

In today's AI landscape, it's easier than ever to build models using powerful libraries. But truly understanding **how** these algorithms work is what builds strong intuition.

This repository is my journey of revisiting the fundamentals of **Machine Learning** and **Deep Learning** by implementing algorithms from scratch, exploring the mathematics behind them, and understanding how they learn.

The goal isn't just to use `fit()`, it's to understand what happens behind it.

## 🎯 What You'll Find

* Implementations of Machine Learning and Deep Learning algorithms
* Step-by-step notebooks explaining the intuition and mathematics
* Visualizations to better understand how algorithms learn
* Well-documented code focused on learning rather than using high-level APIs
